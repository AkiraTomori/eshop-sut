## Primary Heuristic Frameworks

### Nielsen's 10 Usability Heuristics
- Nielsen, J. (1994). *10 Usability Heuristics for User Interface Design*. Nielsen Norman Group.
  - URL: https://www.nngroup.com/articles/ten-usability-heuristics/
  - Abbreviations used: N1–N10

### Norman's 6 Design Principles
- Norman, D. A. (2013). *The Design of Everyday Things: Revised and Expanded Edition*. Basic Books.
  - ISBN: 978-0465050659
  - Principles: Visibility, Feedback, Constraints, Mapping, Consistency, Affordance
  - Abbreviations used: NOR1–NOR6

### Shneiderman's 8 Golden Rules
- Shneiderman, B., Plaisant, C., Cohen, M., Jacobs, S., Elmqvist, N., & Diakopoulos, N. (2016).
  *Designing the User Interface: Strategies for Effective Human-Computer Interaction* (6th ed.). Pearson.
  - ISBN: 978-0134380384
  - Abbreviations used: S1–S8

## Accessibility Standards

### WCAG 2.1 (Web Content Accessibility Guidelines)
- W3C Web Accessibility Initiative. (2018). *Web Content Accessibility Guidelines (WCAG) 2.1*.
  - URL: https://www.w3.org/TR/WCAG21/
  - Level AA criteria applied throughout checklist

### WCAG 2.2 (Web Content Accessibility Guidelines)
- W3C Web Accessibility Initiative. (2023). *Web Content Accessibility Guidelines (WCAG) 2.2*.
  - URL: https://www.w3.org/TR/WCAG22/
  - New criteria: WCAG 2.4.11 Focus Not Obscured, WCAG 2.5.7 Dragging, WCAG 2.5.8 Target Size

### ARIA Authoring Practices Guide
- W3C Web Accessibility Initiative. (2023). *ARIA Authoring Practices Guide (APG)*.
  - URL: https://www.w3.org/WAI/ARIA/apg/
  - Used for: modal focus management, tab widgets, status messages
